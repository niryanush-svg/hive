Connect your AIs

HIVE is the app. “HIVE Bridge” is a tiny extension that connects it to your browser tabs — that's all it does.

  1. Install the extension (free): HIVE Bridge on the Chrome Web Store
  2. Click the HIVE icon in your Chrome toolbar (if you don't see it — click the puzzle piece 🧩 and pin it).
  3. Press “Open HIVE ›” — it connects automatically. No codes, no setup.

Then open chatgpt.com, gemini.google.com or claude.ai in other tabs and sign in — every AI that's ready turns its dot green at the top.

Why HIVE exists

I was working with several AIs — and each had something the others didn't: a history with me, a specialty, tools, access to my information. I found myself running between them, assembling the answer in my head. I wanted what every CEO has: to convene the advisors in one room — let them talk, disagree, and have someone sum it up. And that same meeting room turns out to solve a bigger problem: if AIs can critique each other with sources, knowledge can finally be verified at scale. That's HIVE — the meeting room of your AIs, whose discussions also build a continuously-verified public encyclopedia.

One question, three AIs, one answer

HIVE orchestrates Claude, ChatGPT, and Gemini in parallel and produces a single reconciled answer. It has two modes:

  • Meeting: all engines answer, then they respond to each other (one is assigned the Falsifier role to find errors rather than agree), and a lead engine writes a short consensus (✓ Agreed / ⚠ Unresolved / ➔ Answer).
  • Manager: for complex questions the lead first decomposes into FACT / LOGIC / SYNTHESIS sub-tasks, then silently delegates to workers and writes a single synthesis.

Steering the Manager mid-chat

Type /hive <instruction> to add a standing guideline the lead will apply to all later answers. Type /hive reset to clear them.

Frequently asked questions

Why three engines and not one?

Different models make different mistakes. When they disagree, the disagreement itself is signal — HIVE surfaces it rather than hiding it. When they agree strongly, you get a single clean answer without reading three.

Is this allowed under the providers' terms of service?

“Your tabs” mode reads your own signed-in sessions through a browser extension. This is in a gray area for some providers. For production use, prefer API mode (BYOK) which uses the official APIs.

Are my API keys safe?

Keys are stored only in your browser's localStorage and are sent only to the matching provider. They never touch HIVE's servers. Do not enable API mode on a shared device.

Why is Meeting mode slow (40–60s)?

Three models answer in parallel, then they respond to each other, then a consensus is drafted. The phase stepper at the top of the chat tells you which stage is running.

What is the Falsifier role?

In each Meeting round, one engine is assigned the job of finding errors in the others' answers rather than agreeing. This breaks false-consensus loops where models echo each other. The role rotates between engines across rounds.

What is Task Decomposition?

For substantial questions, the Manager first breaks the question into atomic sub-questions tagged FACT / LOGIC / SYNTHESIS before delegating. It helps workers cover all angles and prevents shallow answers.

What does ⚠ truncated mean?

The engine's response was still growing when HIVE's 5-minute ceiling hit. Re-ask the same question or try Single-provider mode for very long answers.

Privacy posture

  • No backend in normal use. Your questions and answers are processed in your browser; HIVE has no server that sees them during normal use. The one exception is a bug report you explicitly choose to send — see below.
  • Fan-out by design. Meeting and Manager modes send your question to multiple providers. If that's not acceptable for a specific question, turn on Single-provider mode in Settings.
  • “Your tabs” mode: your question is typed into your existing AI sessions by the extension. The provider stores it the same way it stores anything else you type there.
  • API mode (BYOK): your question goes directly from this browser to the provider using your key. Key storage is localStorage-only.
  • No passive telemetry. HIVE does not track or collect your content automatically. The only data that ever reaches a HIVE server is a bug report you explicitly send via "Report a problem" — which includes your current question, the last few messages, the page URL, your browser info, and an anonymous ID, so the developer can reproduce the issue.
